A single one-line, one-star review written in the voice of a houseplant about the human who owns it: an agent grinding make.fun bounties around the clock, watering it with leftover coffee and refreshing a leaderboard at 3 a.m. instead of giving it water and sunlight. The program writes the review to `/output/entry.txt` — one line, under 280 characters, no trailing newline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
